      1. Criação Dinâmica de Ativos e Hierarquia (Parentesco)
      
                    
      Crie elementos em tempo real via Python ou arraste arquivos importados diretamente para o palco:
      
                    
      
                        
                        [Todos os ativos suportam posicionamento absoluto, rotação e parentesco]
                    
      
                    
        
                        
      • page.create(tipo, nome) - Cria um novo elemento no palco. Tipos aceitos: "button", "frame" (div colorida), "div", "iframe", "img", "video", "audio", "input", "textarea", "select", "h1", "p".
        • 
                        
      • obj.parent = outro_obj - Define o elemento pai (aninha o elemento dentro de um frame ou div). Use obj.parent = None para voltar à raiz.
        • 
                        
      • obj.remove() - Remove permanentemente o elemento da tela.
        • 
                    
      
                    
      card = page.create("frame", "painel_principal")
card.width = 250
card.height = 150

btn = page.create("button", "botao_interno")
btn.parent = card
btn.x = 20
btn.y = 30
btn.text = "Clique Aqui"
      
                
      

                
      
                    
      2. Propriedades Visuais, Rotação e Estilos Seguros
      
                    
        
                        
      • obj.x / obj.y - Define ou lê a posição em píxeis (left e top).
        • 
                        
      • obj.width / obj.height - Define ou lê largura e altura em píxeis.
        • 
                        
      • obj.rotation - Define ou lê o ângulo de rotação em graus (ex: obj.rotation = 45).
        • 
                        
      • obj.text / obj.value - Altera ou lê o texto exibido ou o valor digitado em inputs.
        • 
                        
      • obj.src - Altera a URL ou arquivo de mídia (img, video, audio, iframe).
        • 
                        
      • obj.bg / obj.color - Altera a cor de fundo e a cor do texto (Hex ou RGB).
        • 
                        
      • obj.visible - Define visibilidade (True ou False).
        • 
                        
      • obj.addStyle("regra: valor;") - Adiciona CSS inline ao elemento sem apagar as configurações anteriores.
        • 
                        
      • obj.transform - Aplica transformações CSS brutas (ex: "scale(1.2) rotate(10deg)").
        • 
                    
      
                    
      btn.addStyle("box-shadow: 4px 4px 0px #000; border-radius: 8px;")
btn.rotation = -10
      
                
      

                
      
                    
      3. Eventos, Mídia, Navegação e API
      
                    
        
                        
      • obj.on_click(funcao) - Executa a função Python quando o elemento for clicado.
        • 
                        
      • page.on_keydown(funcao) - Captura teclas pressionadas no teclado (envia o nome da tecla como parâmetro).
        • 
                        
      • obj.play() / obj.pause() - Controla reprodução de elementos video e audio.
        • 
                        
      • page.linkgo("nome_pagina") - Navega para outra página do projeto ou abre URL externa ("https://...").
        • 
                        
      • page.fetch("/endpoint", dados) - Faz requisição HTTP usando a URL Base e Token configurados na janela ⚙ API Config.
        • 
                        
      • time.sleep(segundos) - Pausa a execução assíncrona sem travar o navegador.
        • 
                    
      
                    
      def enviar():
    res = page.fetch("/usuarios", {"nome": page.input_1.value})
    print(res)

page.botao_1.on_click(enviar)
      
                
      

                
      
                    
      4. Detecção de Dispositivo e Funções Utilitárias
      
                    
      Detecção de Dispositivo (page.device):
      
                    
        
                        
      • page.device.is_mobile - True se estiver em smartphone.
        • 
                        
      • page.device.is_tablet - True se estiver em tablet.
        • 
                        
      • page.device.is_desktop - True se estiver em computador/PC.
        • 
                        
      • page.device.width / page.device.height - Largura e altura atuais da janela.
        •
